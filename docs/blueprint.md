# **App Name**: Amorem Duo

## Core Features:

- Secure User Authentication: Authentication using 'Him' or 'Her' roles and a magic word, restricting access to only two predefined users.
- Private Chat: Real-time chat interface with text, emoji, and voice note support.  Voice notes are limited to a maximum of 60 seconds.
- Mood Sharing: Display current mood using predefined emojis visible in the chat screen.
- Shared Notes: Calendar-organized notes section, with distinct notes for 'Him' and 'Her' on each date.
- Important Dates Calendar: Calendar to store important dates with titles, descriptions, and notification to the other user upon creation/update.
- Shared To-Do List: Collaborative to-do list where both users can add and complete tasks, marked with their respective colors.

## Style Guidelines:

- Primary color: Deep rose (#850E33) to emphasize love and connection.
- App background color: Light rose (#FFC4C4) for a soft and inviting feel.
- Receiving chat bubble: Moderate rose (#EE6983).
- Receiving chat text: Light rose (#FFC4C4).
- Sending chat bubble: Light beige (#FFF5E4).
- Sending chat text: Deep rose (#850E33), with moderate rose (#EE6983) as needed for accents.
- Font pairing: 'Belleza' (sans-serif) for headers and short amounts of text, paired with 'Alegreya' (serif) for body text.
- Use rounded corners, soft shadows, and avoid harsh borders to create a minimalist, cute, and romantic theme.
- Custom icons that are cute and romantic, consistent with the overall theme.
- Smooth transitions and subtle animations for user interactions to enhance the user experience.
